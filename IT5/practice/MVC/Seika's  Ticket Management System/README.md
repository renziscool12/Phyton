# Seika's Ticket Management System

A Python-based management system designed to organize, manage, and maintain records through CRUD (Create, Read, Update, Delete) operations.

Built using the **Model-View-Controller (MVC)** architecture to keep the application organized, maintainable, and easy to expand.

This project focuses on practicing Python OOP, file handling, modular programming, and structured application development.
